นโยบายความเป็นส่วนตัว

affiliate-ai-crew · มีผลตั้งแต่ 25 กันยายน 2569

หน้าแรก ข้อกำหนดการใช้งาน

1. ภาพรวม

affiliate-ai-crew เป็นเครื่องมืออัตโนมัติที่ติดตั้งและใช้งานโดยเจ้าของช่องเพียงคนเดียว เพื่อเผยแพร่คอนเทนต์ขึ้นบัญชีโซเชียลของตัวเอง แอปไม่เปิดให้บุคคลทั่วไปสมัครใช้งาน และไม่เข้าถึงบัญชีของผู้ใช้รายอื่น

2. ข้อมูลที่แอปเข้าถึง

  • โทเคนการเข้าถึง (access token) ของบัญชีที่เจ้าของอนุญาตไว้เอง — ใช้เพื่ออัปโหลดคอนเทนต์เท่านั้น
  • ชื่อและรหัสช่อง ที่โทเคนนั้นผูกอยู่ — ใช้ยืนยันว่าจะเผยแพร่ขึ้นช่องที่ถูกต้อง
  • ผลการเผยแพร่ เช่น รหัสโพสต์ ลิงก์ และจำนวนการเข้าชม — ใช้สรุปผลของคอนเทนต์
  • ข้อมูลสินค้าสาธารณะ จากหน้าร้านค้าออนไลน์ เช่น ชื่อ ราคา รูปภาพ

แอป ไม่เก็บ ข้อมูลส่วนบุคคลของผู้ชม ไม่เก็บรายชื่อผู้ติดตาม ไม่อ่านข้อความส่วนตัว และไม่มีการติดตามพฤติกรรมผู้ใช้รายบุคคล

3. ข้อมูลถูกเก็บที่ไหน

ข้อมูลทั้งหมดอยู่ในฐานข้อมูล PostgreSQL บนเครื่องคอมพิวเตอร์ส่วนตัวของเจ้าของ ซึ่งเปิดรับการเชื่อมต่อเฉพาะจากเครื่องนั้น (127.0.0.1) ไม่มีเซิร์ฟเวอร์สาธารณะ ไม่มีบริการภายนอกที่เก็บสำเนาข้อมูลเหล่านี้ และไม่มีการขาย แลกเปลี่ยน หรือส่งต่อข้อมูลให้บุคคลที่สามไม่ว่ากรณีใด

4. การใช้ YouTube API Services

แอปนี้ใช้ YouTube API Services เพื่ออัปโหลดวิดีโอขึ้นช่องของเจ้าของเอง เมื่อใช้งานแอปนี้ถือว่าคุณยอมรับ YouTube Terms of Service และ Google Privacy Policy ด้วย

เจ้าของบัญชีสามารถ ถอนสิทธิ์ที่ให้ไว้กับแอปได้ตลอดเวลา ที่หน้า Google security settings เมื่อถอนสิทธิ์แล้ว แอปจะเข้าถึงบัญชีนั้นไม่ได้อีก และโทเคนที่เก็บไว้จะใช้งานไม่ได้ทันที

5. การใช้ TikTok API

แอปใช้ TikTok Content Posting API ในโหมดกล่องแบบร่าง (upload to inbox) เท่านั้น คลิปที่ส่งไปจะยังไม่เผยแพร่จนกว่าเจ้าของบัญชีจะเปิดแอป TikTok แล้วกดโพสต์เอง สิทธิ์ที่ขอมีเพียง user.info.basic และ video.upload และถอนสิทธิ์ได้ในหน้าตั้งค่าความปลอดภัยของบัญชี TikTok

6. ระยะเวลาเก็บข้อมูล

โทเคนจะถูกเก็บไว้เท่าที่ยังใช้เผยแพร่คอนเทนต์อยู่ และถูกเขียนทับทุกครั้งที่ต่ออายุ หากเจ้าของหยุดใช้งานแอปหรือถอนสิทธิ์ ข้อมูลโทเคนจะถูกลบออกจากฐานข้อมูล

7. Summary in English

affiliate-ai-crew is a private automation operated by a single creator to publish content to their own social accounts. It stores OAuth tokens, the connected channel identity, and publishing results in a local PostgreSQL database that only accepts connections from the owner's machine. It collects no viewer data, never shares data with third parties, and is not offered as a service to other users. This app uses YouTube API Services; by using it you agree to the YouTube Terms of Service and the Google Privacy Policy. You may revoke the app's access at any time via Google security settings.
